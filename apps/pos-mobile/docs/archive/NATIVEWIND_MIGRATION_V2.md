# NativeWind V2 — Payment UI

Migrated the primary Payment sheet layout to NativeWind while preserving transaction, checkout, receipt, printer, and payment logic.

Scope:
- Payment sheet header and total
- Payment method selector
- Cash input and presets
- Change summary
- QRIS info
- Sticky payment footer

Receipt confirmation styling remains on the existing StyleSheet because it represents a print-preview document layout and is intentionally kept stable during incremental migration.
