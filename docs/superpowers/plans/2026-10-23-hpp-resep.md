# HPP dari Resep Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pemilik mengisi bahan dan resep di BackOffice, dan HPP serta untung per porsi dihitung otomatis ke `products.hpp`.

**Architecture:** Migrasi `084_hpp_recipes.sql` menambah `ingredients`, `recipe_lines`, `products.hpp_source`, dan fungsi `owner_*` (semua hitungan dan konversi satuan hanya di database). `products.hpp` tetap satu-satunya sumber untuk kasir, transaksi, stok, dan laporan, jadi aplikasi kasir tidak berubah. BackOffice menambah halaman Bahan, editor resep di dialog produk, dan server function yang memanggil RPC itu.

**Tech Stack:** Postgres/Supabase (plpgsql, `supabase/tests/test_*.sql`), TanStack Start + React + zod (`apps/web/apps/backoffice`), `node --test` untuk tes TS.

**Spec:** `docs/superpowers/specs/2026-10-23-hpp-resep-design.md`

## Global Constraints

- Satuan hanya `g`, `kg`, `ml`, `l`, `pcs`. Berat (g, kg), volume (ml, l), hitungan (pcs) adalah tiga keluarga; satuan resep harus satu keluarga dengan satuan kemasan bahan.
- Istilah di layar: "HPP (modal per porsi)" dengan satu kalimat penjelasan. Tidak ada kata sendok atau sachet.
- Hitung hanya di database. Harga per satuan dasar tidak dibulatkan; hanya HPP akhir dibulatkan ke `numeric(14,2)`.
- Hak akses seperti `update_product`: `perform public.assert_catalog_access(p_outlet_id)`.
- Penjualan lama tidak berubah (`transaction_items.hpp_unit` tidak disentuh). Tidak ada perubahan di `apps/pos-mobile`.
- Resep boleh belum lengkap (bahan berharga Rp 0): tetap dihitung dan ditandai perkiraan, tidak memblokir.
- Pesan galat dan teks UI dalam bahasa Indonesia; setiap teks UI baru ditambah ke `EN` di `src/dict.ts`.
- Kerja langsung di `main`, tanpa branch atau worktree. Commit lokal; jangan push kecuali diminta.
- Tes SQL: `PSQL="psql -h /tmp/pgt -p 54329 -U postgres" sh supabase/tests/run_all.sh` dari root repo; lulus bila tidak ada baris `ERROR`/`FAIL`. Tes TS dan tipe: `npm test -w @hermes-pos/backoffice` dan `npm run typecheck -w @hermes-pos/backoffice` dari `apps/web`.

## Review Focus

1. Mengganti satuan kemasan bahan ke keluarga lain saat bahan sudah dipakai resep harus ditolak (bukan menghasilkan HPP salah). Dites di Task 2.
2. Produk ber-resep tidak boleh ditimpa HPP-nya lewat `update_product` atau `owner_save_product` dengan `p_hpp` lain. Dites di Task 3.
3. Menghapus resep (daftar kosong) mengembalikan `hpp_source = 'manual'` dan mempertahankan angka HPP terakhir. Dites di Task 3.
4. Baris transaksi lama tetap memegang `hpp_unit` lamanya setelah hitung ulang. Dites di Task 3.
5. Harga kecil per satuan tidak hilang: Rp 100 per 3 g, pakai 1 g, jadi HPP 33,33. Dites di Task 1.
